Add the /supermoon mode for maximum-thoroughness work: while it is on, the agent plans multi-agent orchestration on every substantive task and pins thinking effort to its highest supported level. Run `/supermoon` to enable it (or `/supermoon on` / `/supermoon off`); `/supermoon <task>` runs one task in the mode.
