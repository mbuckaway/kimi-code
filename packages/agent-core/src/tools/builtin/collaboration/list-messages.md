List the messages you received in this session, newest first. Use it to catch up on peer messages and to get the id needed by `ReplyMessage`.

Each entry shows the message id, the sender name (or sender id when the sender has no name), the sender id, the delivery mode, and a short preview. A message cut at the 100000-character limit is marked `[truncated]`. The header reports how many messages are queued to you and not yet delivered.

Options:
- `from`: only messages from this sender, using an id or name from `ListAgents`.
- `limit`: the maximum number of messages to return. The default is 20 and the maximum is 100.

This tool is read-only. It changes no files and grants no permissions.
