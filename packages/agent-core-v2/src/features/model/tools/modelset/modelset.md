Assigns a model to a role. With `role: "current"` (the default) this switches the model the agent is running on — the switch is refused when the target model's context window is smaller than the current model's. With `role: "default"` it persists the default model. With `role: "planning"` it configures the model used while plan mode is active; the planning model must have the same context window as the default model. Confirm the target id with `modellist` first.
