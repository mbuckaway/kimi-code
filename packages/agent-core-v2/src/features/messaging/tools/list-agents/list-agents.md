List the agents you can message: the root agent (`main`), your ancestors, and every agent in your own subtree, by name or id. Your own entry is never listed. Each entry shows the agent id, its name when one was set, and whether it is running or idle. Use an id or name as the `to` value of `SendMessage`. Every listed agent is a recipient; its id or name is also what `ListMessages` reports as the sender and what `ReplyMessage` resolves from an inbox message. A reply reaches an inbox origin even when that agent is no longer in your subtree. Ids and names from this roster are also accepted by `StopAgent`, `InterruptAgent`, `TagAgent`, and `RenameAgent`. `DismissAgents` removes an agent in your subtree, together with its own subtree, from the roster.
