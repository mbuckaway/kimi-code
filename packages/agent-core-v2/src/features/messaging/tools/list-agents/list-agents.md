List the agents you can message: the root agent (`main`), your parent, and the agents you or the root agent spawned. Your own entry is never listed. Each entry shows the agent id, its name when one was set, and whether it is running or idle. Use an id or name as the `to` value of `SendMessage`. Every listed agent is a recipient; its id or name is also what `ListMessages` reports as the sender and what `ReplyMessage` resolves from an inbox message. Ids and names from this roster are also accepted by `StopAgent`, `InterruptAgent`, `TagAgent`, and `RenameAgent`. `DismissAgents` removes an owned agent from the roster.
