Rename an agent you own. The new name is validated and reserved exactly like a name chosen at spawn time, so no other agent can take it while this agent lives.

The agent id never changes, and the agent stays addressable by its id. Tags are unaffected.

Only an agent you own can be renamed; `main`, yourself, and another agent's subagents are refused. Renaming is not auto-approved, but it stays available in plan mode.
